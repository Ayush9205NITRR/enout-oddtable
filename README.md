# enout-oddtable

The Oddtables single-page site.

`index.html` in this branch is the live site. It is written automatically by
the Oddtables Composer every time the layout is saved — do not hand-edit it,
your changes will be overwritten on the next save.

Serve it with GitHub Pages (Settings -> Pages -> this branch, root folder),
or connect the repo to Netlify / Vercel / Cloudflare Pages.
